# Security policy

## Reporting a vulnerability

Please **do not disclose security vulnerabilities in public issues or pull requests**.

If GitHub private vulnerability reporting is available for this repository, use **Security → Report a vulnerability**. If that option is unavailable, contact the maintainer privately through a contact channel listed on their [GitHub profile](https://github.com/irwitzer). Do not include exploit details in a public issue.

A useful report includes the affected BookStitch version, operating system, reproduction steps, potential impact and, where possible, a minimal example without personal data or copyrighted media.

## Supported versions

Security fixes are considered for the current published release. Older releases are not guaranteed to receive backported fixes. Check [Releases](https://github.com/irwitzer/BookStitch/releases) for the latest available version.

## Scope

Reports about BookStitch's application code, its handling of untrusted audio or image files, and project data are welcome. Vulnerabilities in external components such as FFmpeg or third-party libraries should also be reported to their maintainers when appropriate.

No guaranteed response or remediation timeframe is promised.
